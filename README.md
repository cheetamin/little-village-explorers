# 우리 동네 탐험대

초등 사회 3D 교육게임의 익명 공유 체험판입니다. 지역명·학교명·학급 정보를 제외하고 가상 마을의 창작 이야기와 일반 지역 탐구 자료를 사용합니다. 학교 약속, 안전한 보행로, 호수 이야기의 세 미션이 있습니다.

## 실행

npm ci 후 npm run dev로 실행합니다. npm run build로 만든 dist를 docs에 복사하여 GitHub Pages에서 main /docs로 게시합니다. 기존 학급 데이터나 관리자 계정, 후기 서버 연결은 포함하지 않습니다.

3D 실행에는 WebGL을 지원하는 브라우저가 필요합니다. 지역 시설을 직접 수리하는 활동이 아닌 게임 체험입니다. 실제 시설 문제는 담당 기관에 알립니다.
